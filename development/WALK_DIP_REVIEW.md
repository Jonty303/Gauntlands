# Pelvis dip correction - 9 November 2026

Historical pass: followed by the [knee-stability pass](WALK_KNEE_REVIEW.md).
Shared current reports/media now describe its successor; numbers below remain historical.

## Scope and change

User reported that the slight dip in the [extension pass](WALK_EXTENSION_REVIEW.md)
reads like a limp. R3 Character & Technical Artist leads this bounded timing
correction; R2/R6 integration and validation were performed sequentially by the
same agent. Repository: Jonty303/Gauntlands, existing `human-prototype-01`.
No commits, pushes, branches, merges or gameplay changes.

The sampled vertical trajectory was symmetric between legs to 0.00012 mm.
The working diagnosis is a prolonged low pose followed by a rapid rise/descent,
not an asymmetric leg cycle. Human playback review must confirm whether this
correction addresses the perceived limp.

Only the pelvis-height keys and their explanatory comment changed in the
[generator](../tools/blender/build_locomotion.py). The new Hermite keys
`(phase, root offset in metres, slope in metres/cycle)` are
`(0,-.041,-.04)`, `(.025,-.0415,0)`, `(.27,-.0035,0)`, `(.50,-.041,-.04)`.
They repeat each half-cycle with matching endpoint values/slopes. Brief shallow
settling now leads into one continuous rise and fall. The local target is less
abrupt vertical motion while retaining soft extension and planted contact.

All other tuning is preserved: shoulders, fists, foot/toe roll, cadence, swing
flexion guide and the 5 mm reach safety margin. The height-dependent airborne
ankle correction is recomputed. Idle bounds and prescribed planted targets match
the prior export exactly. This trades the broad near-13-degree support plateau
for a more gradually changing support pose; the knee at 0.30 seconds is 14.689
degrees. It does not restore the old crouched stance.

R3 -> R2/R6 deliverables: generator, [editable derivative](../assets/Blender%20Models/Human-Male-Locomotion.blend),
[GLB](../prototype/assets/human_locomotion.glb), refreshed
[pose bounds](../prototype/tests/locomotion_bounds.json), build/validation reports
and media. Rig, geometry, units, axes, 137 bones, nine source shape keys, packed
textures, 8-influence export, 60 Hz bake, 4-second Idle, 1.2-second Walk,
0.9 m/s reference speed, 60% stance and existing viewer transitions are preserved.
Sprite dimensions/facing order are not applicable. Validator/viewer code unchanged.

## Validation

Blender 5.2.3 LTS build and full exported validation exited 0: 241 Idle frames,
73 Walk frames and 72 half-frame floor/knee checks. No thresholds were relaxed.

| Measure | Before | After |
| --- | --- | --- |
| Pelvis vertical range | 43.171 mm | 37.917 mm |
| Peak sampled vertical speed | 0.36256 m/s | 0.19524 m/s |
| Peak sampled descent speed | 0.35256 m/s | 0.19524 m/s |
| Lowest pose in first step | 0.083 s | 0.033 s |
| Knee at contact / loading / support | 13.234 / 23.933 / 13.077 degrees | 13.234 / 20.323 / 14.689 degrees |
| Maximum authored knee change per 60 Hz frame | 4.807 degrees | 5.354 degrees |

Peak vertical speed falls 46%; descent speed falls 45%. Knee speed increases
slightly but passes the existing <6-degree limit, including half-frame samples
(5.354 degrees normalised). Minimum knee bend is 12.180 degrees. Loop endpoint
vertex difference is zero. Sampled hand-self, body-cloth, cloth-self, inside-vertex
and hand-thigh intersection checks are zero. Minimum hand-thigh clearance:
15.869 mm. Walk floor minima: +1.953 mm authored, +1.965 mm intermediate.

Godot 4.5.2 headless editor import, `test_locomotion.gd` and
`test_locomotion_viewer.gd` exited 0. Maximum pose bounds error is 0.050187 mm;
cross-fade and viewer floor minima are +0.604 and +1.666 mm. GPU capture and all
three recording modes exited 0, as did the GIF encoder. Matched Godot pose
images were inspected. Source/export hashes, curve value/slope continuity,
Python syntax, documentation links, GIF cadence and diff whitespace were checked.

[Comparison metrics](../tools/blender/locomotion_previews/dip_metrics.json) were
generated by `%TEMP%/gauntlands-compare-dip.py`. Baseline backup:
`%TEMP%/gauntlands-dip-before-20261109-001713`.

R2/R6 technical gates pass; human feel/naturalness acceptance remains pending.
