# Leg extension and recovery pass - 8 November 2026

Historical pass: followed by the [pelvis dip correction](WALK_DIP_REVIEW.md).
Shared current reports/media now describe the successor; numbers below remain historical.

## Scope and handoff

User authorised a more extended, exaggerated but fluid walk with soft knees and
no snapping. R3 leads; R2/R6 integration and validation were performed sequentially
by the same agent. Work remains in `human-prototype-01`, Jonty303/Gauntlands.
No commits, pushes, branches or merges. Human artistic acceptance is pending.

The [landing pass](WALK_LANDING_REVIEW.md) is the comparison baseline, backed up at
`%TEMP%/gauntlands-extension-before-20261108-234915`. The local target for this pass
is roughly 10-15 degrees of supporting-knee flexion through a broad supported
pose, while preserving loading and recovery. This is a tuning target, not a
project-wide anatomical rule.

## Changes and interfaces

The [generator](../tools/blender/build_locomotion.py) raises and broadens the
supported pelvis pose. Hermite root-height keys repeat every half-cycle:
`(phase, metres, slope in metres/cycle)` = `(0,-.041,-.06)`, `(.08,-.044,0)`,
`(.20,-.007,.11)`, `(.30,-.001,0)`, `(.36,-.002,-.10)`, `(.45,-.033,-.30)`,
`(.50,-.041,-.06)`. Loop values and slopes match.

The airborne ankle receives up to 25.990 mm of additional lift when its planned
path would extend the knee too early. A soft reach correction blends over 1.5 mm;
its minimum-flexion guide uses `(phase, degrees, degrees/cycle)` keys
`(.60,28,0)`, `(.75,56,-80)`, `(.85,38,-260)`, `(.94,18,-140)`, `(1,11,-70)`.
The existing 5 mm leg-reach safety margin remains. Planted targets, horizontal
foot paths, foot/toe roll settings, shoulders and fists retain their settings.
Airborne vertical foot paths deliberately change.

The [validator](../tools/blender/test_locomotion.py) now checks knee movement halfway
between baked Walk frames, normalised to the existing <6 degrees per 60 Hz frame
limit. No tolerances were relaxed. The settings and per-frame ankle corrections
are recorded in [build.json](../tools/blender/locomotion_previews/build.json).

R3 -> R2/R6 artifacts: generator, validator, [editable derivative](../assets/Blender%20Models/Human-Male-Locomotion.blend),
[GLB](../prototype/assets/human_locomotion.glb), refreshed
[pose bounds](../prototype/tests/locomotion_bounds.json), reports and review media.
Viewer code is unchanged. Preserved interfaces: metres; Blender Z-up/-Y-forward,
Godot Y-up/+Z-facing; 137 bones, nine source shape keys, packed textures;
60 Hz bake, 4-second Idle, 1.2-second Walk, 0.9 m/s, 60% stance, half-cycle leg
offset, eight-influence export and existing transition rules. Sprite dimensions
and facing order are not applicable; no sprite pipeline or gameplay changes.
